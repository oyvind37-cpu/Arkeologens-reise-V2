ARKEOLOGENS REISE v5.6 BASIC

UTGANGSPUNKT
- Bygget direkte på v5.5.5 FINAL-pakken.
- Godkjent Aurora v5.2.1-figur er beholdt.
- 9-sceneprologen, gravkammeret, kisten, kompasset, feltdagboken og ørkenscenen er beholdt.

NYTT I v5.6 BASIC
- Mykere akselerasjon og brems i hovedscenen.
- Aurora stopper mer naturlig i stedet for å fryse momentant.
- Kort snu-animasjon ved retningsskifte.
- Rolige tilfeldige se-seg-rundt-bevegelser når Aurora står stille.
- Bøye-/undersøkelsesbevegelser ved arkeologiske interaksjoner.
- Rekke-/plukkbevegelse ved Horus-mekanismen og kompasset.
- Kompasset vises kort i Auroras hånd etter registrering i feltdagboken.
- Samme bevegelsesprinsipp er koblet til gravkammer og ørken der det er trygt.
- Versjonsmarkører og cache-busting er oppdatert til v5.6 BASIC.

IKKE EN DEL AV BASIC-BUILDEN ENNÅ
- Ekte gange mot/fra kamera.
- Full kroppsskjelett-animasjon med separate armer/ben.
- Fri bruk av arkeologspade.
- 3D-kamera og 3D-miljø.

Disse punktene krever en større animasjons-/3D-løsning og passer naturlig i videre
v5.6.x-arbeid og senere Godot 4-versjon.

GITHUB
1. Pakk ut ZIP-filen.
2. Last opp alle filene i mappen til GitHub-repoets root.
3. Erstatt filer med samme navn.
4. Behold mystisk_musikk.mp3 i repoet dersom den allerede ligger der.
5. På iPhone/Safari kan gammel cache kreve ny fane eller ny start fra Hjem-skjerm.
